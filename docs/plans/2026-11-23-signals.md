## Goal

- The `signals` component writes meeting, speaker and participant events
  from Chrome over CDP, so the data day records real meeting timelines.

## Scope

- In: everything in ADR-0014 "Module layout" and "Tests"; the port from
  the Go files named in ADR-0014 "Port source" (now under `legacy/`).
- Out: fresh DOM saves from a live call (owner). Platform APIs.

## Steps

1. Seed `testdata/discovery/` and `testdata/dom/` from the Go tests.
2. Pure core with table tests: meeting detection, speaking-class
   discovery, speaker debounce, participants.
3. Collector against a fake CDP (HTTP and WebSocket on `127.0.0.1:0`).
4. JS against saved DOM pages in headless Chromium, marked `chrome`.
5. Enable its line in `services/pipeline.py`. Check that Chrome with no debug port
   gives no fault storm (ADR-0014 "Failure modes").
6. Real-host smoke: if a Chrome with `--remote-debugging-port` runs on
   this host, run `odsodctl run signals` on a temp root for 30 s and check
   that no error is logged. Do not open or change any tab.

## Done when

```sh
uv run pytest src/odsod_daemon/components/signals -m "not chrome"
mise run build
```

## Decisions to confirm

- Tie-break in discovery: equal-length changed classes go to the
  lexicographically smallest, so discovery is deterministic. The Go code
  used map order.
- A stop records `at` as the last seen speaking time plus one poll period,
  as ADR-0014 says. The Go tracker used the last seen time plus the stop
  grace instead.
- A code change in the tab ends the old meeting with `cause: tab-closed`.
  The old meeting's tab is gone, and the cause list has no closer value.
- At restart, the open meeting continues only when the first poll sees the
  same platform and code and at least one tile. Otherwise it ends with
  `cause: restart`, also when the same code shows a lobby.
- The restart `meeting-end` and the empty `speaking` before it share one
  `at`: the process start.
- Teams uses discovery, because no saved Teams DOM page shows a stable
  speaking marker on `voice-level-stream-outline`. ADR-0014 allows this
  until such a page exists.
- `testdata/dom/meet.html` is synthetic, built to the Meet JS selectors.
  No live Meet page was saved. `teams.html` comes from the Go test.
- Title stripping removes the prefixes `Meet – `, `Meet - `, `Meet — `,
  `Google Meet – `, `Google Meet - `, and the Teams suffixes
  ` | Microsoft Teams`, ` - Microsoft Teams`, ` | Teams`, ` - Teams`.
- A stale `no-speaking-indicator` fault is cleared at start, because the
  process that wrote it is gone.
- Signals rewrites `run/health/pipeline.json` from a fresh read on each
  change, so it keeps faults of other pipeline components. No shared
  health object exists yet.
- `participants` is written only after its set is stable for
  `participants_stable_s`, so a meeting shorter than 5 s writes none.
- The fake CDP uses two ephemeral ports on `127.0.0.1`: one HTTP server
  for `/json/list`, one WebSocket server for `Runtime.evaluate`. The tab
  list returns the WebSocket URL.
- The tab list timeout is 5 s, from the Go client. ADR-0014 has no config
  value for it.
- `run signals --once` does one tab poll and one speaking poll.
- `mise run build` now runs the Chrome tests when a Chromium binary
  exists, and skips them when it is missing.
