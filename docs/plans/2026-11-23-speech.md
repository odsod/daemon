## Goal

- The three speech components turn the audio buffer into `utterances/`,
  `asr/` and `text/` records, live and with `--once`.
- The pipeline survives a kill at any step with no lost or doubled text.

## Scope

- In: everything in ADR-0012 "Module layout" and "Tests", the dictation
  parts included (mask, presence gate, dictation lane), tested with
  scripted records.
- Out: the dictation component itself. Bench measures (WER, language,
  latency). The capitalized-word guard (deferred).

## Steps

1. Silero model: add `models/silero_vad.onnx` from a v5 release tag of the
   source in ADR-0012 "Segmentation", pin the tag and SHA-256 in `vad.py`, test shapes on a fixture.
2. Pure core with table tests: `cutter`, `mask`, `queue`, `request`,
   `filters`, `guard`, `language`, `prompt`.
3. Workers: segmentation `runner`, transcription `worker` with the
   inference fault rules, cleanup `worker` with two lanes.
4. `--once` for all three (ADR-0012 "Drain mode"; segmentation reads to
   the end of the audio and closes an open utterance there).
5. Enable the three lines in `services/pipeline.py`; add `pipeline` to
   `install.contract.SERVICES`.
6. System test from ADR-0012 "Tests": capture fake, then the three
   components with the fake servers, kill at each step.
7. Real-host smoke on a temp root (`ODSOD_DAEMON_ROOT`, with the two
   loopback URLs of ADR-0010 in its `config/config.json`, and `uv run
   odsodctl`). First check that `uv run python -c 'from odsod_daemon.lib
   import power; print(power.on_mains())'` prints True on this host. Then write a fixture clip into the audio
   buffer at a known time with `lib.audio` helpers, then run
   `odsodctl run segmentation --once`, `transcription --once` against the
   whisper server on 8178, `cleanup --once` against 8179. Re-record the
   llama pairs of inference-recordings with the final prompts. Compare the `text`
   records with the clip's reference text by eye and with
   `lib.textmatch.overlap`. Write the overlap in Progress log.

## Decisions to confirm

- Restart also reads ambient utterance ends. This closes the crash window
  between appending an utterance and appending its coverage.
- The requested ONNX model is package data, with its upstream MIT license.

- `lib.clock.monotonic()` uses the running event loop clock, with the system
  monotonic clock outside a loop. A failing regression check showed that
  the original clock could not measure virtual backoff time.
- In drain mode, battery deferral exits non-zero after 60 s, leaving work
  pending, like host deferral.

- Service `--once` drains in composition order so downstream work includes
  output produced in the same invocation. Live services remain concurrent.

- The system capture fake writes the hourly audio seam directly because
  the capture component is outside this plan and is still a scaffold.
- Restart comparisons use one-to-one audio interval overlap above 95%,
  since resetting VAD at coverage can shift a later boundary by a frame.
  They also require equal counts and no duplicate input IDs.
