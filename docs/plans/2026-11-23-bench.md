# Plan: bench (stretch)

- Status: Draft
- Depends on: [speech](2026-11-23-speech.md)
- Design: [ADR-0019](../adr/0019-bench.md),
  PRD [benchmarking](../prd/benchmarking.md)

## Goal

- `odsodctl bench` makes cases, runs setups in a sandbox and reports
  scores, so phase 3 can start on the recorded day at once.

## Scope

- In: everything in ADR-0019 "Module layout" and "Tests", with fakes.
- Out: `bench accept` on real cases (owner only). Real cases (phase 3).

## Steps

1. Pure core with table tests: case selection, fingerprint, scoring.
2. `bench cases`, `list`, `delete`, `accept`.
3. Sandbox run through `odsodctl run transcription --once` and
   `cleanup --once` with `ODSOD_DAEMON_ROOT` (ADR-0010 "Bench runs
   speech in a sandbox").
4. `bench report --json`; enable the `bench` line in the root `cli.py`.

## Done when

```sh
uv run pytest src/odsod_daemon/components/bench
mise run build
```

- `bench cases`, then `bench run <setup>`, then `bench report --json` on a
  temp root with fakes gives one row per measure, and the host root does
  not change.

## Decisions to confirm

- Ambient targets are per `(channel, language)` stratum, so
  `ambient_per_language` gives 50 Swedish and 50 English cases on each of
  `mic` and `sys` (ADR-0019 AC-1 says "at least", so both readings hold).

- `settings` merge order is the host `speech` section, then
  `asr.settings`, then `cleanup.settings` for a `pipeline` setup. The
  manifest stores that merged section.

- `prompt_sha256` hashes both lane prompts (name and bytes, or `builtin`
  when the file is absent), because the manifest has one field for the
  ambient and the dictation prompt.

- Sandbox times are sequential: a case starts after the previous case
  ends plus 5 s, so case audio never overlaps inside one hour file.

- `live.json` becomes a live result for ambient and dictation cases only.
  Interaction cases wait for the stage 2 measures.

- Live dictation latency is `ready_ms`: `text` `ts` minus the utterance
  `end` minus 150 ms post-roll. The row is labeled "text-ready, partial".
  The release-to-paste timing log needs the dictation component, which is
  not built.

- `bench report --json` prints `{"rows": [...]}`.

- The sandbox runs the `odsodctl` script next to the running interpreter,
  so tests never need `uv` on `PATH`.

- `bench accept` without `--draft-by` is owner-only (ADR-0019). The smoke
  accepted no reference.

- WER and glossary scores are percent, rounded to 2 decimals. Percentiles
  use nearest rank. A row appears for a setup as soon as it has one
  result in that group, even with no accepted reference yet.

- The cloud adapter rule is `adapters.check_contract(adapter, cloud=True)`.
  It has no caller until a cloud adapter exists.
