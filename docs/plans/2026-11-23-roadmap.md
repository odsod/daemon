Last steps tonight (orchestrator, on the integrated tip):

1. Run the Done when of every Done plan.
2. Wheel check: `uv build --wheel -o <tmp>`; the wheel holds the unit
   templates, `silero_vad.onnx` and the cleanup prompts.
3. Rehearsal under real systemd, with nothing in `HOME`:
   - `uv tool install` the wheel with `UV_TOOL_DIR` and `UV_TOOL_BIN_DIR`
     in a temp dir; copy the data-day config into a temp root.
   - `systemd-run --user --unit=odsod-rehearse-capture -p Type=notify -p
     WatchdogSec=30 -E ODSOD_DAEMON_ROOT=<root> <bin>/odsodctl run capture`,
     and the same for `pipeline` with `WatchdogSec=120`.
   - After 150 s: `systemctl --user show -p ActiveState,NRestarts` gives
     `active` and `0` for both. Stop both, delete the temp dirs.
4. Write the morning report in Progress log: plans Done and Blocked, the
   integrated change ID, the rehearsal result, Decisions to confirm from
   every plan.

### Phase 2: the data day (owner)

1. Read the morning report. In
   `~/Workspaces/github.com/odsod/recorder/always-on`, check that
   `jj log -r @-` is the change it names.
2. Know this first: capture records whenever the graphical session runs,
   also when you are away from the desk. The tray icon shows it (tray
   ships tonight).
3. `install -Dm600 /tmp/agent-team/recorder-always-on/config.json
   ~/.config/odsod-daemon/config.json` (keep an existing one), then
   `mise run deploy`, then `odsodctl status`. Expect OK.
4. Play 10 s of any video. `pactl list short source-outputs` names the
   monitor of the real sink (tonight the default sink was `auto_null`).
   A `sys` line shows in `odsodctl transcript` within a minute.
5. Work as usual. `odsodctl pin` at topic changes helps bench later.
6. If the pipeline fails, leave capture on:
   `journalctl --user -u odsod-daemon-pipeline -n 50`, then
   `systemctl --user reset-failed odsod-daemon-pipeline && systemctl
   --user start odsod-daemon-pipeline`. Pause only for privacy or if
   capture itself misbehaves.
7. Optional dictation trial (keys and dictation are Done, not shipped):
   it needs `mise run deploy:system` (keys replaces `odsod-keys.service`)
   and a manual session:
   `systemd-run --user --unit=odsod-trial-session odsodctl run session`.
   Follow the owner steps in the keys and dictation plans. The escape
   chord test comes first, with an SSH session open. Skipping it keeps
   the data day safe.
