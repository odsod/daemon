# Plan: capture and retention

- Status: Draft
- Depends on: [python-scaffold](2026-11-23-python-scaffold.md)
- Design: [ADR-0011](../adr/0011-capture.md),
  [ADR-0003](../adr/0003-filesystem-interface.md) (audio format),
  PRD [ambient-recording](../prd/ambient-recording.md)

## Goal

- The `capture` component writes both channels to the audio buffer, with
  its events and health, and the `capture` service runs it.
- `odsodctl retention` deletes old hour files.

## Scope

- In: everything in ADR-0011 "Module layout" and "Tests", the `capture`
  service file, the `retention` command.
- Out: the owner checks in ADR-0011 "Build without hardware".
  `capture_latency_ms` stays 0 until the owner's spike. Echo
  cancellation (deferred).

## Steps

1. Pure core with table tests on the virtual-time loop: the anchor, the
   writer offsets and hour split, the stall and suspend rules, the mic
   checks (ADR-0011 "Block loop and time anchoring", "Writer", "Stall,
   suspend and restart", "Mic checks").
2. Fake `pw-record` and fake `pactl` scripts in the component's tests.
3. I/O shell: one `pw-record` per channel, `pactl subscribe`, health
   faults, `start`, `stop` and `gap` records, `sd_notify`.
4. Enable the `capture` line in `services/capture.py`; add `capture` to
   `install.contract.SERVICES`.
5. `retention` and its command; enable its line in the root `cli.py`.
6. System tests from ADR-0011 "Tests" in the root `tests/`.
7. Real-host smoke (this host has a mic and PipeWire):
   `ODSOD_DAEMON_ROOT=$(mktemp -d)`, run `odsodctl run capture` for 60 s,
   then SIGTERM. Use `uv run odsodctl`. Check both channel files grow at 32,000 bytes per
   second, the `start` and `stop` records, and the health file. Check
   with `pactl list source-outputs` that the sys channel reads a monitor.
   Write `pactl get-default-sink` and the monitor name in Progress log.
   If the sink is `auto_null`, write `sys smoke: not proven (null sink)`.
   Delete the temp root.

## Done when

```sh
uv run pytest src/odsod_daemon/components/capture src/odsod_daemon/components/retention

```
