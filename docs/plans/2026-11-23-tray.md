# Plan: tray (stretch)

- Status: Draft
- Depends on: [install-and-control](2026-11-23-install-and-control.md)
- Design: [ADR-0018](../adr/0018-control.md) ("tray", "Timing"),
  PRD [health-and-control](../prd/health-and-control.md),
  PRD [dictation](../prd/dictation.md) (AC-1)

## Goal

- The tray shows the health state, the dev mark and Dictating, and gives
  Pause and Resume.

## Scope

- In: the `tray` component and its ADR-0018 tests with
  `QT_QPA_PLATFORM=offscreen`; `tray` in `install.contract.SERVICES` when
  they pass.
- Out: icon art beyond the ADR. If PySide6 had no 3.14 wheel
  (python-scaffold step 1), this plan is Dropped.

## Steps

1. Worker on `health.evaluate()`, ticking every `tray_interval_s`, and a
   follow on `run/status.json` that pushes each `mode` change.
2. Menu: Pause, Resume. Notifications for new Errors.
3. Enable the line in `services/tray.py`.

## Done when

```sh
QT_QPA_PLATFORM=offscreen uv run pytest src/odsod_daemon/components/tray
mise run build
```

- A `mode` change reaches the icon slot in at most 200 ms in the offscreen
  test.

## Progress log

- Step 1: the worker evaluates health on the tick and follows
  `run/status.json`; tests cover evaluation, status application and new Error
  notifications.
- Step 2: the icon, tooltip, reason lines, Pause or Resume and new Error
  notifications are in place; the offscreen test shows Dictating within 200 ms
  of a status mode change.
