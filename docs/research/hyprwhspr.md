## Scope

- System-wide Linux speech-to-text dictation daemon for Wayland and X11 compositors (Hyprland, Sway, Niri, GNOME, KDE Plasma) ([README.md](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/README.md#L52-L58), [AGENTS.md](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/AGENTS.md#L5)).
- Supports batch local transcription, cloud REST/WebSocket streaming, file transcription (`hyprwhspr transcribe`), long-form pause/resume dictation, and an auxiliary HTTP meeting-recorder script ([README.md](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/README.md#L166-L182), [utils/meeting-recorder.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/utils/meeting-recorder.py#L1-L28)).

## Architecture (processes, services, IPC, state)

- Main daemon runs as a systemd user service (`config/systemd/hyprwhspr.service`) launching `bin/hyprwhspr` -> `lib/main.py` (`hyprwhsprApp` composed of six mixins in `lib/src/app/`: `RecordingMixin`, `ShortcutsMixin`, `SilenceMixin`, `FeedbackMixin`, `ControlMixin`, `RecoveryMixin`) ([config/systemd/hyprwhspr.service](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/config/systemd/hyprwhspr.service#L14-L24), [lib/main.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/main.py#L83-L90)).
- Single-instance lock lives at `$XDG_RUNTIME_DIR/hyprwhspr/hyprwhspr.lock` via `fcntl` ([lib/main.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/main.py#L69-L80), [lib/src/paths.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/paths.py#L36)).
- Child processes managed by the daemon:
  - Optional GTK4 layer-shell OSD daemon (`lib/mic_osd/runner.py`) controlled with `SIGUSR1`/`SIGUSR2` and runtime files (`visualizer_state`, `mic_osd_level_feed`, `transcript_preview`, `mic_osd.pid`) ([lib/mic_osd/runner.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/mic_osd/runner.py#L1-L63), [lib/src/paths.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/paths.py#L35-L39)).
  - Private `ydotoold` child spawned lazily on `$XDG_RUNTIME_DIR/hyprwhspr-ydotool.sock` (`-P 0600`) only when uinput paste/typing is needed ([lib/src/ydotoold_session.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/ydotoold_session.py#L35-L60)).
  - Pinned `llama-server` Unix-socket sidecar when using `qwen3-asr` ([lib/src/backends/qwen3_asr_backend.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/backends/qwen3_asr_backend.py#L1-L90)).
- IPC in `RecordingControlServer` (`lib/src/recording_control_server.py`):
  - Named FIFO `$XDG_RUNTIME_DIR/hyprwhspr/recording_control` accepts `start`, `start:<lang>`, `stop`, `release`, `cancel`, `submit`, `model_unload`, `model_reload` ([lib/src/recording_control_server.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/recording_control_server.py#L13-L55)).
  - Unix domain socket `$XDG_RUNTIME_DIR/hyprwhspr/hyprwhspr.sock` serves single-subscriber capture clients (`hyprwhspr record capture`), file transcription requests, recovery, and diagnostics ([lib/src/recording_control_server.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/recording_control_server.py#L114-L219)).
- State files in `$XDG_RUNTIME_DIR/hyprwhspr/` expose `recording_status`, `audio_level`, `visualizer_state`, `longform_state`, `model_unloaded`, and `recovery_requested`/`recovery_result` for status bars and scripts ([lib/src/paths.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/paths.py#L28-L54)).
- Background monitors watch USB hotplug (`pyudev`), PulseAudio/PipeWire events (`pulse_monitor.py`), and D-Bus suspend/resume (`suspend_monitor.py`) to recover audio streams and GPU contexts ([lib/main.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/main.py#L289-L296)).

## Audio capture (API, rate, buffering, system audio)

- Dictation capture uses `sounddevice` (PortAudio) with `channels = 1`, `chunk_size = 1024`, `dtype = np.float32`, and initial `sample_rate = 16000` synced to the resolved device's `default_samplerate` ([lib/src/audio_capture.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/audio_capture.py#L27-L73), [lib/src/audio_capture.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/audio_capture.py#L350-L360)).
- Backends requiring 16 kHz resample with `soxr.resample(..., quality="HQ")` and pad/trim to exact expected sample count ([lib/src/audio_resampler.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/audio_resampler.py#L38-L56)).
- Device selection resolves PipeWire/PulseAudio source names via `pactl get-default-source` and routes through the sound server instead of raw ALSA `hw:` devices unless `hw:` is explicit; it explicitly refuses `.monitor` output sources as microphones ([lib/src/audio_capture.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/audio_capture.py#L169-L263), [lib/src/audio_capture.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/audio_capture.py#L945-L976)).
- In-memory audio chunks accumulate in `self.audio_data` with a hard cap of `_MAX_BUFFER_SECONDS = 3600`, a stall detector at `_CALLBACK_STALL_SECONDS = 2.0`, and off-thread stream teardown with `_TEARDOWN_DEADLINE_SECONDS = 30.0` so wedged PortAudio `stop()`/`close()` calls cannot hang the main thread ([lib/src/audio_capture.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/audio_capture.py#L32-L36), [lib/src/audio_capture.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/audio_capture.py#L1331-L1399)).
- Optional `keepalive_stream` (default `False`) keeps a silent input stream open to avoid USB/ALSA cold-start timeouts ([lib/src/config_manager.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/config_manager.py#L227-L231), [lib/src/audio_capture.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/audio_capture.py#L130-L134)).
- Optional playback suppression (`audio_ducking`, `audio_ducking_mode`: `duck` or `pause`, `audio_ducking_percent`: 50) pauses MPRIS players and/or ducks other application streams during recording ([lib/src/playback_suppressor.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/playback_suppressor.py#L1-L86)).
- System audio capture is not part of the main dictation daemon; it lives in the separate `utils/meeting-recorder.py` script using `parec --device=<sink>.monitor --rate=16000 --channels=1 --format=s16le --raw` ([utils/meeting-recorder.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/utils/meeting-recorder.py#L110-L150)).

## VAD and segmentation

- Silence-based segmentation for continuous dictation and auto-stop uses rolling RMS energy (`audio_capture.rolling_avg_level`, 8-sample `deque`), polled every `0.1` seconds (`_POLL_INTERVAL`) ([lib/src/audio_capture.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/audio_capture.py#L86-L87), [lib/src/app/silence.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/app/silence.py#L14-L26)).
- Noise-floor auto-calibration samples 6 readings over 0.6 s and sets threshold to `max(min(samples) * 2, 2e-4)`:
  ```python
  noise_floor = min(samples)
  return max(noise_floor * 2, 2e-4)
  ```
  ([lib/src/app/silence.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/app/silence.py#L16-L25)).
- Continuous mode flushes and pastes after `continuous_silence_seconds` (default `2.0`) of quiet once speech occurred, skipping chunks under `0.5` s; optional `silence_timeout` (default `0`, disabled) auto-stops toggle/auto/continuous sessions only after speech arms it ([lib/src/config_manager.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/config_manager.py#L58-L60), [lib/src/app/silence.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/app/silence.py#L66-L179), [lib/src/app/silence.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/app/silence.py#L225-L227)).
- Backend-level Silero VAD:
  - `pywhispercpp`: optional native Silero VAD (`pywhispercpp_use_vad`, default `False`), auto-downloads ~1 MB `ggml-silero` model and passes `vad=True, vad_model_path=...` to `pywhispercpp.model.Model` ([lib/src/backends/pywhispercpp_backend.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/backends/pywhispercpp_backend.py#L112-L136)).
  - `onnx-asr`: Silero VAD enabled by default (`onnx_asr_use_vad: True`), routed only for clips `>= onnx_asr_vad_min_duration` (default `30` s), with `vad_batch_size=1` (overriding `onnx-asr`'s default of 8 to prevent ~4 GB CUDA arena spikes) ([lib/src/onnx_model.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/onnx_model.py#L41-L47), [lib/src/backends/onnx_asr_backend.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/backends/onnx_asr_backend.py#L145-L155)).
  - `faster-whisper`: `faster_whisper_vad_filter` defaults to `True` and passes `vad_filter=True` directly to `WhisperModel.transcribe` ([lib/src/backends/faster_whisper_backend.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/backends/faster_whisper_backend.py#L205-L219)).
- Backend-specific pause/chunk handling:
  - `parakeet-cpp` compresses pauses longer than `1.0` s (`_shorten_pauses`, 20 ms frames within 12 dB of the 10th percentile) because Parakeet silently drops sentences after ~1.5 s pauses ([lib/src/backends/parakeet_cpp_backend.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/backends/parakeet_cpp_backend.py#L15-L35)).
  - `qwen3-asr` chunks long clips near `_CHUNK_TARGET_SECONDS = 110`, searching 25 s back and 10 s forward in 100 ms RMS buckets for a pause ([lib/src/backends/qwen3_asr_backend.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/backends/qwen3_asr_backend.py#L62-L79)).
- Long-form mode saves 16 kHz mono 16-bit WAV segments atomically (`mkstemp` + `fsync` + `os.replace`) to `$XDG_DATA_HOME/hyprwhspr/temp/longform_segments` up to `long_form_temp_limit_mb` (500 MB) ([lib/src/segment_manager.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/segment_manager.py#L23-L106)).

## ASR (backends, models, language handling, prompts, custom vocabulary)

- Eight backends registered in `BACKENDS` (`lib/src/backends/__init__.py`) behind the `WhisperManager` facade (`lib/src/whisper_manager.py`):
  1. `pywhispercpp` (default; CPU, CUDA, Vulkan, ROCm; default model `base`, `beam_search` with `beam_size=5`) ([lib/src/backends/pywhispercpp_backend.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/backends/pywhispercpp_backend.py#L43-L120), [lib/src/config_manager.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/config_manager.py#L81-L100)).
  2. `onnx-asr` (ONNX Runtime CPU/CUDA; default `nemo-parakeet-tdt-0.6b-v3` INT8, plus optional `orukeet` INT8 fine-tune) ([lib/src/backends/onnx_asr_backend.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/backends/onnx_asr_backend.py#L45-L101), [lib/src/onnx_model.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/onnx_model.py#L27-L47)).
  3. `faster-whisper` (CTranslate2 CUDA/CPU; default `base`, `compute_type='auto'` -> `int8`; preloads pip `nvidia-cublas`/`cudnn` with `RTLD_GLOBAL`) ([lib/src/backends/faster_whisper_backend.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/backends/faster_whisper_backend.py#L45-L162)).
  4. `cohere-transcribe` (`CohereLabs/cohere-transcribe-03-2026` via `transformers`, CUDA `bfloat16` or CPU `float32`, optional `torch.compile`) ([lib/src/backends/cohere_backend.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/backends/cohere_backend.py#L39-L100), [lib/src/config_manager.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/config_manager.py#L184-L187)).
  5. `parakeet-cpp` (experimental native C API via `ctypes`, CPU/Vulkan) ([lib/src/backends/parakeet_cpp_backend.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/backends/parakeet_cpp_backend.py#L38-L96)).
  6. `qwen3-asr` (local `llama-server` sidecar over Unix socket; default `1.7b-q8_0`, CPU/Vulkan; strips `language X<asr_text>` preamble) ([lib/src/backends/qwen3_asr_backend.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/backends/qwen3_asr_backend.py#L45-L90), [lib/src/config_manager.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/config_manager.py#L142-L145)).
  7. `rest-api` (HTTP multipart WAV upload with ordered `rest_fallback_endpoint_urls` on connection error / 429 / 5xx; supports AssemblyAI dictation `keyterms_prompt` and `llm_response`) ([lib/src/backends/rest_api_backend.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/backends/rest_api_backend.py#L319-L400)).
  8. `realtime-ws` (WebSocket streaming for OpenAI Realtime, Google Gemini, ElevenLabs, Deepgram, Phonon, and custom endpoints; supports `transcribe` and `converse` modes and optional `realtime_live_typing`) ([lib/src/backends/realtime_ws_backend.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/backends/realtime_ws_backend.py#L40-L150), [lib/src/config_manager.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/config_manager.py#L155-L169)).
- Memory lifecycle: `model_idle_unload_minutes` unloads local models when idle and reloads on next recording; local GPU backends (`pywhispercpp`, `faster-whisper`, `cohere-transcribe`) reinitialize automatically after >30 min idle or suspend/resume ([lib/src/config_manager.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/config_manager.py#L170), [lib/src/whisper_manager.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/whisper_manager.py#L250-L298), [lib/src/whisper_manager.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/whisper_manager.py#L414-L436)).
- Language handling: `language` defaults to `None` (auto-detect); `pywhispercpp` and `faster-whisper` explicitly run `auto_detect_language()`/`detect_language()` before transcribing so prompt selection matches the spoken language; `secondary_shortcut` + `secondary_language` allow per-recording language overrides; `task: "translate"` translates to English ([lib/src/backends/pywhispercpp_backend.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/backends/pywhispercpp_backend.py#L373-L400), [lib/src/backends/faster_whisper_backend.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/backends/faster_whisper_backend.py#L181-L218)).
- Prompts and custom vocabulary: `resolve_whisper_prompt(language)` checks `whisper_prompt_<lang>`, then `whisper_prompt`, and falls back to `ENGLISH_PROMPT` only for `en`/unknown so non-English audio is not pulled into English ([lib/src/backends/base.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/backends/base.py#L140-L157), [lib/src/config_manager.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/config_manager.py#L24-L26)).

## Post-processing (LLM cleanup, prompts, glossary, replacements)

- Built-in LLM cleanup: Not found (searched `lib/` and `utils/` with `rg`). The only LLM-cleaned output is remote provider `llm_response` on AssemblyAI dictation REST calls ([lib/src/backends/rest_api_backend.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/backends/rest_api_backend.py#L347-L353)).
- Users can wire external LLM cleanup via `post_transcription_hook` (shell command with `post_transcription_hook_timeout` = 5.0 s): stdin receives the preprocessed transcript, non-empty stdout replaces it, empty stdout preserves it, exit code `77` consumes it without pasting, and other errors preserve the original text ([lib/src/text_injector.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/text_injector.py#L106), [lib/src/text_injector.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/text_injector.py#L1888-L1931)).
- Built-in deterministic preprocessing (`preprocess_text` in `lib/src/text_processing.py`) runs in this order:
  1. Flattens newlines to spaces, then applies case-insensitive `word_overrides` (default `{'hyper whisper': 'hyprwhspr'}`), matching whole-word boundaries for multi-char keys and substrings for single-char keys ([lib/src/text_processing.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/text_processing.py#L38-L49), [lib/src/text_processing.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/text_processing.py#L153-L154)).
  2. Optional `filter_filler_words` (default `False`, list `['uh', 'um', 'er', 'ah', 'eh', 'hmm', 'hm', 'mm', 'mhm']`) ([lib/src/config_manager.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/config_manager.py#L84-L85), [lib/src/text_processing.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/text_processing.py#L52-L55)).
  3. ## Hotkeys on Wayland/KDE (mechanism, hold vs toggle)

- Primary mechanism: hardware-level `evdev` listener reading `/dev/input/event*` via `select.select` (requires `input` group membership), with `pyudev` hotplug attachment (`keyboard_hotplug: True`) and optional `keyboard_device_names` allowlist ([lib/src/global_shortcuts.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/global_shortcuts.py#L224-L273), [lib/src/global_shortcuts.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/global_shortcuts.py#L596-L639), [lib/src/global_shortcuts.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/global_shortcuts.py#L663-L759)).
- Exclusive grab (`grab_keys`, default `False`): when enabled, grabs keyboard devices and re-emits non-shortcut events through `evdev.UInput`, suppressing only the completing non-modifier key and never suppressing modifier releases to prevent stuck keys; filters out its own `hyprwhspr` virtual keyboard to avoid feedback loops ([lib/src/global_shortcuts.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/global_shortcuts.py#L285-L299), [lib/src/global_shortcuts.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/global_shortcuts.py#L781-L848)).
- Layout awareness: compiles the XKB keymap via `xkbcli` (queried from `hyprctl devices -j`) to map single letters to physical evdev keycodes on non-QWERTY layouts ([lib/src/global_shortcuts.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/global_shortcuts.py#L50-L117)).
- Alternative compositor-native mode: `external_bindings: True` disables `GlobalShortcuts` so KDE/Hyprland/Sway/GNOME shortcuts call `hyprwhspr record start|stop|toggle|cancel` (writing to the `recording_control` FIFO) ([lib/src/app/shortcuts.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/app/shortcuts.py#L14-L21)).
- Five recording modes in `ShortcutsMixin` (`lib/src/app/shortcuts.py`):
  - `toggle` (default): press starts, press stops.
  - `push_to_talk`: press starts, release stops; optional `push_to_talk_lock_seconds` latches hands-free when held past threshold, ending on next press.
  - `auto`: hybrid tap/hold with `_tap_threshold = 0.4` s (hold >= 400 ms acts as push-to-talk; tap < 400 ms toggles, and arms `silence_timeout` only on release so holds are never cut off):
    ```python
    if hold_duration >= tap_threshold:
        self._stop_recording()
    else:
        if not started_this_press:
            self._stop_recording()
        else:
            self._autostop_start_silence_monitor()
    ```
  - `continuous`: toggle on/off with auto-paste on silence.
  - `long_form`: primary key toggles record/pause; `long_form_submit_shortcut` transcribes and pastes all segments ([lib/src/app/shortcuts.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/app/shortcuts.py#L34-L83), [lib/src/app/shortcuts.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/app/shortcuts.py#L195-L340)).
- Debounce is `0.1` s on both press and release; rejects trigger if extra modifier keys are held (`extra_modifiers = (pressed_keys - target_keys) & MODIFIER_KEYS`) ([lib/src/global_shortcuts.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/global_shortcuts.py#L261-L263), [lib/src/global_shortcuts.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/global_shortcuts.py#L850-L895)).

## Text delivery (paste vs type, tools, clipboard restore, per-app, unicode)

- Strategy: clipboard copy + synthetic paste chord (`_inject_via_clipboard_and_hotkey`); explicit `inject_mode` (`wtype`/`ydotool_type`) is deprecated because direct typing drops characters at speed ([lib/src/text_injector.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/text_injector.py#L1843-L1854)).
- Exception on GNOME/Mutter Wayland: uses `ydotool type --key-delay 5 --key-hold 5 -- <text>` only when text is pure ASCII and the active XKB layout matches US ASCII positions (`_layout_is_type_safe()`), otherwise falls back to clipboard + `ydotool` paste chord with temporary switch to a Latin GNOME input source (`_gnome_force_latin_layout`) ([lib/src/text_injector.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/text_injector.py#L1211-L1291), [lib/src/text_injector.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/text_injector.py#L1988-L2005)).
- Backend dispatch order in `_paste_via_clipboard` after sleeping `clipboard_settle_delay` (default `0.15` s):
  1. Sway XWayland: `ydotool` (preferred) or `xdotool` (after confirming X11 active window matches Sway focus); rechecks focus before dispatch and refuses delivery if focus moved ([lib/src/text_injector.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/text_injector.py#L1457-L1485), [lib/src/text_injector.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/text_injector.py#L2088-L2109)).
  2. X11: `xdotool key --clearmodifiers <chord>` ([lib/src/text_injector.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/text_injector.py#L1039-L1056), [lib/src/text_injector.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/text_injector.py#L2117-L2118)).
  3. Hyprland: `hyprctl dispatch` (Lua `hl.dsp.send_shortcut` then legacy `sendshortcut`, checking stdout/stderr for `invalid dispatcher`) -> `wtype` -> `ydotool` ([lib/src/text_injector.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/text_injector.py#L980-L1024), [lib/src/text_injector.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/text_injector.py#L2119-L2124)).
  4. Other Wayland (including KDE Plasma): `wtype` (`-p Insert` release-only keymap activation before `-M <mod> -k <key> -m <mod>`), falling back to private `ydotool` with staggered key events (15 ms after modifier press, 10 ms before release) and configurable `paste_keycode` / `paste_keycode_wev` / `ydotool_modifier_overrides` (e.g. `{"ctrl": "capslock"}`) ([lib/src/text_injector.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/text_injector.py#L950-L978), [lib/src/text_injector.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/text_injector.py#L1096-L1190), [lib/src/text_injector.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/text_injector.py#L2125-L2152)).
  5. Clipboard-only fallback: leaves text on clipboard without restoring the old clipboard if no paste tool exists ([lib/src/text_injector.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/text_injector.py#L2154-L2163)).
- Clipboard save/restore: saves bytes + MIME type via `wl-paste --list-types` and `wl-paste --no-newline --type <mime>` (falling back to lazy `pyperclip` with `xclip`/`xsel`, avoiding GTK3 conflict with GTK4); writes with `wl-copy --type text/plain;charset=utf-8` so text starting with `"From "` is not sniffed as `application/mbox`; restores on a background thread after `clipboard_clear_delay` (default `5.0` s) only if the clipboard still matches the injected text and `_clipboard_generation` has not advanced ([lib/src/text_injector.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/text_injector.py#L58-L90), [lib/src/text_injector.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/text_injector.py#L1293-L1403)).
- Per-app detection and rules: queries Sway IPC, `niri msg --json focused-window`, `hyprctl activewindow -j`, `xdotool`/`xprop` (`WM_CLASS`), and finally an isolated subprocess AT-SPI probe for GNOME/KDE native Wayland; terminals (25+ listed including `konsole`, `kitty`, `ghostty`, `alacritty`, `foot`, `wezterm`) auto-get `ctrl+shift+v`, other apps get `ctrl+v`; `applications` config maps normalized app identifiers to custom chords (e.g. `{"emacs": {"auto_paste": "ctrl+y"}}`) or `{"auto_paste": false}` (hands-off, no clipboard write) ([lib/src/text_injector.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/text_injector.py#L583-L811), [lib/src/text_injector.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/text_injector.py#L1958-L1970)).

- Keeps `_last_text` in memory for `hyprwhspr record copy-last|paste-last|clear-last` recovery ([lib/src/text_injector.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/text_injector.py#L1786-L1811)).

## Known pitfalls (top Linux/Wayland issues from the tracker)

- **PortAudio / ALSA-PipeWire teardown crashes**: `Pa_CloseStream` SIGSEGV, `Pa_Terminate` SIGABRT, and `snd_pcm_poll_descriptors` SIGSEGV when stopping/closing wedged streams concurrently; required single-thread halt-then-close with a 30 s deadline and escalation (https://github.com/goodroot/hyprwhspr/issues/282).
- **Audio routing to raw ALSA `hw:` or ignored PipeWire device changes**: matching device names directly against PortAudio bypassed PipeWire, and Bluetooth/USB source changes were missed without service restart (https://github.com/goodroot/hyprwhspr/issues/234, https://github.com/goodroot/hyprwhspr/issues/195, https://github.com/goodroot/hyprwhspr/issues/183, https://github.com/goodroot/hyprwhspr/issues/245).
- **KDE Plasma / GNOME Wayland paste failures**: `wtype` is blocked by Mutter (and sometimes problematic on KDE), while `ydotool` sends physical evdev keycodes so swapped CapsLock/Ctrl prints `"v"` instead of pasting and non-Latin layouts fail to resolve `KEY_V` (https://github.com/goodroot/hyprwhspr/issues/133, https://github.com/goodroot/hyprwhspr/issues/178, https://github.com/goodroot/hyprwhspr/issues/238).
- **Hyprland dispatcher edge cases**: `hyprctl dispatch` exits 0 even on `"Invalid dispatcher"` (masking fallback), and `send_shortcut` can toggle NumLock off (https://github.com/goodroot/hyprwhspr/issues/218, https://github.com/goodroot/hyprwhspr/issues/283).
- **Hotkey leakage into apps**: without exclusive `grab_keys`, shortcuts leak into focused apps like VS Code (https://github.com/goodroot/hyprwhspr/issues/141).
- **ONNX Runtime CUDA memory retention**: `onnx-asr`'s default VAD `batch_size=8` spiked VRAM to ~4 GB on 2-minute clips and held it in the ORT arena until unload (https://github.com/goodroot/hyprwhspr/issues/302).
- **Parakeet pause drops**: `parakeet.cpp` silently drops sentences spoken after ~1.5 s pauses (https://github.com/goodroot/hyprwhspr/issues/268).
- **Overlay focus stealing & stuck status**: GTK4 layer-shell degrades to a focus-stealing window on compositors without `wlr-layer-shell`, and auto-hide could hang if `recording_status` was never cleared (https://github.com/goodroot/hyprwhspr/issues/249, [lib/mic_osd/notification_presenter.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/mic_osd/notification_presenter.py#L4-L8)).

## Ideas for the recorder

- **Copy: PipeWire-first source routing and `.monitor` guard for dictation vs explicit `.monitor` for meetings**. For always-on capture, use `parec` (or PipeWire native) on both the default mic and `<default_sink>.monitor` in separate buffers so `[You]` and `[System]` stay separated without diarization, while rejecting `.monitor` sources when selecting a mic ([utils/meeting-recorder.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/utils/meeting-recorder.py#L110-L227), [lib/src/audio_capture.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/audio_capture.py#L967-L976)).
- **Copy: Private `ydotoold` + safe clipboard save/restore + KDE terminal auto-detect**. Run a private `ydotoold` socket (`-P 0600`) lazily instead of fighting a shared system daemon, pass `--type text/plain;charset=utf-8` to `wl-copy` (avoiding `application/mbox` sniffing), guard clipboard restore with a generation counter and content comparison, and support `ydotool_modifier_overrides` for Caps/Ctrl remaps ([lib/src/ydotoold_session.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/ydotoold_session.py#L35-L60), [lib/src/text_injector.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/text_injector.py#L1096-L1135), [lib/src/text_injector.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/text_injector.py#L1324-L1403)).
- **Copy: Evdev hold-key handling with UInput safety and modifier-release pass-through**. For hold-Alt dictation on KDE Wayland, `evdev` gives reliable press/release events without compositor portal limits; never suppress modifier key-up events, filter out your own virtual keyboard by name, and reject triggers when extra modifiers are held (so `Alt+Tab` or `Alt+F4` does not start dictation) ([lib/src/global_shortcuts.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/global_shortcuts.py#L285-L299), [lib/src/global_shortcuts.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/global_shortcuts.py#L781-L862)).
- **Copy: Language-aware Whisper prompt resolution and hallucination filtering**. Do not send an English `initial_prompt` to non-English audio, and normalize/drop known Whisper silence phantoms before LLM cleanup or paste ([lib/src/backends/base.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/backends/base.py#L140-L157), [lib/src/hallucination.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/hallucination.py#L10-L50)).
- **Copy: Transient replaceable desktop notifications or `gtk4-layer-shell` fed from the existing capture stream**. Never open a second audio stream for a level meter, and never show a regular toplevel window that steals focus from the paste target ([lib/main.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/main.py#L317-L335), [lib/mic_osd/notification_presenter.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/mic_osd/notification_presenter.py#L66-L82)).
- **Avoid: PortAudio for always-on PipeWire capture**. Issue #282 and 1,953 lines of workaround code in `lib/src/audio_capture.py` (stall timers, off-thread `abort()`/`close()` deadlines, ALSA stderr fd redirection, keepalive streams) show PortAudio's ALSA-PipeWire bridge is fragile across hotplug and suspend; talking to PipeWire directly (`parec`/libpipewire) is simpler for an always-on Linux recorder (https://github.com/goodroot/hyprwhspr/issues/282, [lib/src/audio_capture.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/lib/src/audio_capture.py#L1331-L1399)).
- **Avoid: Fixed 300-second blind chunking for meetings**. `utils/meeting-recorder.py` slices on a 5-minute `time.sleep` timer without VAD, which cuts mid-sentence; Silero VAD segmentation is much cleaner ([utils/meeting-recorder.py](https://github.com/goodroot/hyprwhspr/blob/62ee89920d47b403d3d2b3b5e16dbc0b9a380d61/utils/meeting-recorder.py#L229-L240)).
