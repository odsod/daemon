## Scope

- Offline hold-to-talk voice dictation daemon for Linux (X11 and Wayland), macOS, and Windows ([README.md](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/README.md#L5-L9), [README.md](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/README.md#L45-L49)).
- Includes voice commands, macros, file transcription (`yazses transcribe`), and continuous room meeting capture with speaker diarization and optional local-LLM minutes ([README.md](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/README.md#L45-L62)).
- Includes many opt-in accessibility and experimental modules (gaze tracking, EMG/biosignal switches, AT-SPI voice pilot, MCP server, read-back TTS), all gated off by default ([pyproject.toml](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/pyproject.toml#L171-L390)).

## Architecture (processes, services, IPC, state)

- Multi-process design with separate entry points: `yazses` CLI (`yazses.cli:main`), `yazses-daemon` (`yazses.main:run` -> `yazses.core.daemon:run`), `yazses-tray` (`yazses.tray.app:run`), `yazses-settings` (`yazses.settingsui.app:run`), `yazses-overlay` (`yazses.overlay.app:run`), and `yazses-agent` (`yazses.remote.agent:main`) ([pyproject.toml](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/pyproject.toml#L151-L169), [main.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/main.py#L1-L6)).
- On Linux, `LinuxLifecycle` manages a PID file under `data_dir`, detached daemon spawning, and a `systemd --user` unit at `~/.config/systemd/user/yazses.service` ([lifecycle.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/platform/linux/lifecycle.py#L28-L95)).
- IPC uses newline-delimited JSON-RPC over a Unix-domain socket (`AF_UNIX`, `0o600` permissions) served on a daemon background thread; CLI, tray, and overlay poll daemon state over this socket ([ipc.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/platform/linux/ipc.py#L1-L20), [server.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/ipc/server.py#L1-L90)).
- Daemon state (`_DaemonState`) tracks `TrayState` (starting at `LOADING`), `audio_level`, `input_device`, `last_good_device`, `silent_streak`, `target_ok`, `app_class`, and `field_role` ([daemon.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/core/daemon.py#L323-L355)).

## Audio capture (API, rate, buffering, system audio)

- Uses `sounddevice.InputStream` (PortAudio) imported lazily on first open so headless commands do not crash on `Pa_Initialize()` ([recorder.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/audio/recorder.py#L17-L42)).
- Captures 16 kHz mono `float32` audio; default hold-to-talk cap is 300 s (`[audio] max_record_seconds = 300`), while meeting mode uses `accumulate=False` and `max_seconds=0` to stream chunks to disk ([config.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/config.py#L197-L202), [recorder.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/audio/recorder.py#L90-L105), [recorder.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/audio/recorder.py#L179-L186)).
- Retries transient PortAudio open failures with front-loaded delays `(0.05, 0.55)` seconds, tracks mid-recording stream death (`stream_interrupted`), and uses a generation counter so a `stop()` during `start()` closes the newly opened stream ([recorder.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/audio/recorder.py#L61-L78), [recorder.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/audio/recorder.py#L167-L229)).
- Includes `PreSpeechRingBuffer` (`padding_ms` default 300 ms in `[accessibility]`), though the config comment notes the ring buffer is deliberately unfed for standard hold-to-talk and instead prepends silence before decode ([padding.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/audio/padding.py#L13-L70), [config.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/config.py#L430-L439)).
- `DeviceMonitor` polls the default input every 3 s, resolves PipeWire's `default` alias via `wpctl status`, and can auto-heal back to `last_good_device` after 3 consecutive silent discards ([config.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/config.py#L207-L221), [devices.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/audio/devices.py#L243-L287)).
- System audio capture: Not found. Checked `src/yazses/audio/` and `src/yazses/meeting/`; capture only opens a single PortAudio input microphone (`wpctl status` is used only to resolve the default mic name).

## VAD and segmentation

- Dictation energy gate uses `mean(|audio|) < config.vad_threshold` (default `0.01`, configurable via `[accessibility] vad_threshold`) ([vad.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/audio/vad.py#L3-L9), [vad_calibrated.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/audio/vad_calibrated.py#L9-L17), [config.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/config.py#L441)).
- `AdaptiveThreshold` watches consecutive silent discards (`DEFAULT_MIN_DISCARDS = 3`) and proposes lowering the threshold to `max(loudest * 0.6, 0.0005)` while refusing to lower for dead/muted mics (`proposed > loudest`) ([adaptive_vad.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/audio/adaptive_vad.py#L29-L93)).
- Before Whisper decode, a Silero speech-presence gate (`[accessibility] speech_presence_check = True`) uses the Silero ONNX model already bundled inside `faster-whisper` with `SPEECH_THRESHOLD = 0.3` (lower than 0.5 to avoid dropping single words) and fails open on error ([speech_presence.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/audio/speech_presence.py#L35-L90), [config.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/config.py#L442-L449)).
- Meeting mode segments continuous audio with `UtteranceSegmenter`:
  ```python
  hangover_ms: int = 700
  min_utterance_ms: int = 400
  max_utterance_ms: int = 30000
  ```
  It stamps each emitted utterance with its audio-sample start offset (`last_start_s`) rather than wall-clock decode time ([segmenter.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/meeting/segmenter.py#L27-L90)).
- Meeting mode `[meeting] vad_backend` defaults to `"calibrated"` (RMS gate); `"silero"` loads `silero-vad` ONNX at 512-sample frames (`silero_threshold = 0.5`), though the docstring warns `silero-vad` pulls ~3 GB of `torch` + CUDA packages on Linux ([vad.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/meeting/vad.py#L38-L61), [silero_vad.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/meeting/silero_vad.py#L11-L63), [config.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/config.py#L1950-L1951)).

## ASR (backends, models, language handling, prompts, custom vocabulary)

- Three pluggable STT engines via `stt/factory.py`: `faster-whisper` (default, CTranslate2), `parakeet` (NVIDIA Parakeet TDT via `onnx-asr`), and `moonshine` (`useful-moonshine-onnx`); missing optional backends fall back to `faster-whisper` with a logged warning ([factory.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/stt/factory.py#L30-L132), [config.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/config.py#L15-L23)).
- Default Whisper settings: `model = "base.en"`, `language = "en"`, `device = "cpu"`, `compute_type = "int8"`, `beam_size = 0` (delegates to faster-whisper default 5), `condition_on_previous_text = True`, `idle_unload_s = 0` ([config.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/config.py#L43-L164)).
- `_load_model` tries `WhisperModel(..., local_files_only=True)` first before allowing a Hugging Face Hub download, avoiding >15-minute hangs on firewalled or captive-portal networks ([faster_whisper.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/stt/faster_whisper.py#L13-L68)).
- Language handling: `language = ""` omits the kwarg for Whisper auto-detect; incompatible engine/model/language pairs (such as `fa` with `base.en`) are refused with `LanguageUnsupportedError` instead of silently typing English ([factory.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/stt/factory.py#L44-L66), [faster_whisper.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/stt/faster_whisper.py#L143-L169)).
- Prompts and custom vocabulary: `vocabulary.txt` (next to `config.toml`) and `[stt] initial_prompt` are merged with `BUILTIN_PROMPT = "The app is called YazSes."` placed last so it survives Whisper's 223-token tail truncation (`PROMPT_TOKEN_BUDGET = 223`), and the built-in English phrase is withheld for non-English languages ([vocabulary.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/stt/vocabulary.py#L24-L83), [faster_whisper.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/stt/faster_whisper.py#L172-L207)).
- Streaming partial decode (`[streaming] enabled`) is off by default because commit re-decodes the whole utterance, increasing end-to-end latency on `base.en` from 1.42 s to 2.21 s ([config.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/config.py#L330-L352)).

## Post-processing (LLM cleanup, prompts, glossary, replacements)

- Deterministic cleanup runs first: `clean_text` strips blank artefacts (`[BLANK_AUDIO]`, `(blank)`, `[INAUDIBLE]`, `[silence]`) and leading dots ([cleaner.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/postprocess/cleaner.py#L3-L11)).
- `hallucination.py` drops curated whole-transcript YouTube-outro ghost phrases (`"thanks for watching"`, `"please subscribe"`, etc.) and repetition loops (4+ repeats for single-word units, 3+ for multi-word units, allowing truncated tail prefixes), skipping non-ASCII text to protect CJK/Persian ([hallucination.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/postprocess/hallucination.py#L14-L148)).
- Disfluency filter strips a conservative filler list (`um`, `uh`, `er`, `ah`, `hmm`, `you know`, `i mean`, `okay so`, `so um`, `so uh`) and handles in-burst self-correction triggers (`no wait`, `scratch that`, `delete that`, etc.) unless preceded by negations/articles/copulas ([config.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/config.py#L356-L396)).
- Post-decode glossary/vocabulary correction (`[stt] vocab_correction = False` by default, shared by `[hotwords]`) matches Latin tokens against `vocabulary.txt` using an exact Soundex-like consonant `phonetic_key` plus Levenshtein distance (`DEFAULT_MAX_DISTANCE_RATIO = 0.34`, `MIN_TOKEN_LENGTH = 4`, up to 4-word sliding windows excluding stopwords, leaving already-known terms untouched) ([vocab_correct.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/postprocess/vocab_correct.py#L42-L250), [hotwords.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/postprocess/hotwords.py#L1-L38)).
- Optional LLM cleanup (`[filters.disfluency] llm_enabled = False`) supports local GGUF via `llama-cpp-python` (`n_ctx=2048`, `temperature=0.0`) or Ollama HTTP (`http://localhost:11434`, default model `qwen2.5:1.5b`) with a strict loopback check (`is_loopback_endpoint`) unless `llm_allow_remote_endpoint = True` ([llm_cleanup.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/postprocess/llm_cleanup.py#L41-L103), [llm_cleanup.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/postprocess/llm_cleanup.py#L221-L300)).
- Default LLM cleanup prompt ([config.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/config.py#L409-L415)):
  ```text
  Reformat only. Do not add facts and do not remove information. Preserve every proper noun, number, code identifier, and URL exactly as given. Fix capitalization, punctuation, and paragraph breaks; do not change word choices. Output ONLY the reformatted text with no preamble, no explanation, and no markdown fences.
  ```
- LLM output guards reject rewrites outside `[0.5, 2.0]` length ratio or missing any critical token (proper nouns, code identifiers, or boundary-matched numbers so `"100"` cannot silently become `"1000"`), falling back to the uncleaned text ([llm_cleanup.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/postprocess/llm_cleanup.py#L110-L215), [config.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/config.py#L416-L419)).

## Hotkeys on Wayland/KDE (mechanism, hold vs toggle)

- Linux default hotkey backend is `EvdevHoldListener` reading `/dev/input/event*` via `python-evdev`, which works on both X11 and Wayland (including KDE Plasma) if the user is in the `input` group ([hotkey.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/platform/linux/hotkey.py#L46-L70), [evdev_hold.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/hotkeys/evdev_hold.py#L82-L128)).
- Default Linux hotkey is `right_alt` (`KEY_RIGHTALT`); also supports `left_alt`, `right_ctrl`, `left_ctrl`, `right_meta`, `left_meta`, `right_shift`, `left_shift`, `space`, and optional dedicated `[hotkey] command_key` ([hotkey.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/platform/linux/hotkey.py#L13-L38), [config.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/config.py#L181-L193)).
- `EvdevHoldListener` listens on all real hardware keyboards simultaneously, filters out virtual uinput devices (`ydotool`, `uinput`, `virtual`, `wtype`, `yazses`), and rescans `/dev/input` every 1.0 s for USB hotplug while cleanly ending an active hold if the held keyboard disconnects ([evdev_hold.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/hotkeys/evdev_hold.py#L18-L24), [evdev_hold.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/hotkeys/evdev_hold.py#L82-L278)).
- Modifier keys start recording immediately on key-down (`value == 1`) with 0 leaked characters so voice onset is not clipped; character keys (`space`) wait for `hold_threshold_ms` (default 500 ms) and backspace leaked characters ([evdev_hold.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/hotkeys/evdev_hold.py#L138-L165), [hold_detector.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/hotkeys/hold_detector.py#L1-L32)).
- `X11GrabHotkey` (`XGrabKey` via `python-xlib`) exists for strict snap confinement on X11 and does not work on pure Wayland ([hotkey_xgrab.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/platform/linux/hotkey_xgrab.py#L1-L40)).
- Toggle mode: Not found. Checked `src/yazses/hotkeys/`, `src/yazses/platform/linux/hotkey*.py`, and `src/yazses/config.py`; hold-to-talk only, with toggle mode tracked as open feature request [#869](https://github.com/MSKazemi/yazses/issues/869).

## Text delivery (paste vs type, tools, clipboard restore, per-app, unicode)

- Wayland backend selection ladder in `inject/registry.py` (`auto` mode):
  1. `ydotool` (rank 10): types via `ydotool type`, preferred because it works in terminals and does not clobber the clipboard. Checks binary, socket in `$YDOTOOL_SOCKET` / `$XDG_RUNTIME_DIR/.ydotool_socket` / `/tmp/.ydotool_socket`, and write access to `/dev/uinput` ([registry.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/inject/registry.py#L325-L335), [auto.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/inject/auto.py#L27-L185)).
  2. `portal` (rank 20): `xdg-desktop-portal` `RemoteDesktop` via `jeepney` (`persist_mode=2`, restore token saved on disk, idle release after 60 s). Requires explicit user consent (`portal_consent = "ask"`) unless inside a strict snap, because it triggers a desktop screen-sharing indicator ([registry.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/inject/registry.py#L48-L57), [registry.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/inject/registry.py#L336-L347), [portal.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/inject/portal.py#L68-L155)).
  3. `wtype` (rank 30): wlroots only; explicitly marked unavailable on `gnome`, `kde`, and `plasma` because Mutter and KWin do not implement `virtual-keyboard-manager-v1` ([registry.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/inject/registry.py#L267-L288), [registry.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/inject/registry.py#L348-L357)).
  4. `clipboard` (rank 100, fallback): `wl-copy -- <text>`, sleep 150 ms (`_CLIPBOARD_SETTLE_S = 0.15`), then send `Ctrl+V` via `ydotool` (40 ms key delay) or `wtype` ([clipboard.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/inject/clipboard.py#L16-L56)).
- `YdotoolInjector` handles both `ydotool` 0.1.x (Ubuntu/Debian, `--key-delay`, symbolic key names, exits 0 on parse errors) and 1.x (`-d 6 -H 6`, numeric `<keycode>:<state>`). On 1.x it sends a post-type key-up sweep for keycodes `2..57` plus `(97, 100, 125, 126)` to prevent stuck-key repeat floods and stuck `Right Alt` ([ydotool.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/inject/ydotool.py#L30-L128), [ydotool.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/inject/ydotool.py#L337-L458)).
- Unicode handling: `YdotoolInjector` splits text into ASCII and non-ASCII runs, verifies all non-ASCII characters are producible up front (preventing half-typed text before clipboard fallback), and types non-ASCII runs via `UnicodeInjector` (`libxkbcommon` + private `/dev/uinput` device) ([ydotool.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/inject/ydotool.py#L343-L357), [ydotool.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/inject/ydotool.py#L459-L505), [unicode.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/inject/unicode.py#L1-L57)).
- Clipboard restore: Not found. Checked `src/yazses/inject/clipboard.py`, `src/yazses/system/clipboard.py`, and `src/yazses/platform/linux/injector.py`; `ClipboardInjector` overwrites the clipboard and `registry.py` explicitly sets `clobbers_clipboard=True` ([registry.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/inject/registry.py#L387-L389)).
- Per-app delivery: `AtspiFocusTracker` (opt-in `python3-pyatspi`) resolves focused widget editability (`target_guard`), widget role (`field_role`), and `app_class` for tone profiles (`postprocess/profiles.py`), but `ClipboardInjector` does not switch between `Ctrl+V` and `Ctrl+Shift+V` for terminals ([target.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/inject/target.py#L48-L119), [profiles.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/postprocess/profiles.py#L14-L21), [clipboard.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/inject/clipboard.py#L35-L45)).

## UI feedback (overlay, tray, notifications)

- Overlay (`yazses-overlay`): separate PySide6 process polling daemon status over IPC and drawing sonar ripples near the cursor; automatically suppressed on native Linux Wayland sessions unless `QT_QPA_PLATFORM` is set, because Qt's `WindowDoesNotAcceptFocus` has no Wayland equivalent and the overlay steals focus from the target app ([overlay/app.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/overlay/app.py#L1-L130), [daemon.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/core/daemon.py#L290-L307)).
- Tray (`yazses-tray`): PySide6 `QSystemTrayIcon` polling daemon IPC; shows daemon state and orange silent-streak warning, and lets the user pick/pin mics, recalibrate, open settings, or stop the daemon ("Quit tray" leaves the daemon running) ([tray.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/platform/linux/tray.py#L1-L120)).
- Notifications: Linux uses `notify-send` with `--wait` and `--action` (libnotify >= 0.8) for clickable recovery toasts (`[Re-calibrate]`, `[Pin this mic]`, `[Ignore]`), using `urgency=critical` only for actionable prompts and `urgency=normal` with a 10 s timeout for informational toasts, plus an `atexit` hook to kill orphaned `notify-send` processes ([notify.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/system/notify.py#L1-L111)).

## Meeting features (system audio, mic mute, diarization, speakers, summaries)

- System audio capture: Not found. Checked `src/yazses/meeting/` and `src/yazses/audio/`; YazSes does not mute or unmute the OS mic, though it detects muted/dead capture via `capture_state` (`no_signal` / `no_speech`) and `capture_gap` (`elapsed_s - duration_s > max(10s, 2%)`) ([store.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/meeting/store.py#L54-L148), [controller.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/meeting/controller.py#L263-L284)).
- Hybrid live + batch pipeline: during the meeting, `MeetingController` streams raw audio to `audio.wav` and runs `UtteranceSegmenter` + STT on a background worker thread into `live.jsonl` and `live-transcript.md` (with a 180-minute auto-stop cap and 5 s stall reporting). At stop, `finalize_meeting` runs a batch Whisper + diarization pass over the full WAV ([controller.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/meeting/controller.py#L36-L256), [config.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/config.py#L1923-L1958)).
- Diarization and speakers: default backend is `SherpaDiarizer` (`sherpa-onnx`, CPU ONNX: `sherpa-onnx-pyannote-segmentation-3-0.onnx` + `3dspeaker-eres2net-base.onnx`, `min_duration_on=0.3`, `min_duration_off=0.5`, `cluster_threshold=1.2`, optional `pyannote.audio` alternative). Supports matching enrolled speaker voiceprints (`speechbrain` ECAPA embeddings) and post-hoc cluster merge/rename from `transcript.json` without re-diarizing ([diarizer.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/recimport/diarizer.py#L18-L125), [config.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/config.py#L1936-L1955), [store.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/meeting/store.py#L1-L9)).
- Quality guard: `meeting/quality.py` checks for batch decode collapse (top trigram share > 0.20, distinct trigram ratio < 0.35, repeat run >= 12, or major word-count disagreement against `live.jsonl`); if suspect or if a capture gap occurred, `audio.wav` is preserved even when `retain_audio = False`, and LLM minutes are skipped on collapsed/empty transcripts ([quality.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/meeting/quality.py#L40-L60), [finalize.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/meeting/finalize.py#L81-L128), [controller.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/meeting/controller.py#L278-L284)).
- Summaries/minutes: opt-in (`[meeting] notes = False`) turn-aware map-reduce over local GGUF (`llama-cpp-python`, `notes_ctx_tokens = 4096`, `notes_max_tokens = 1024`, `notes_window_turns = 40`, GBNF JSON grammar) outputting summary, decisions, action items with owners, and per-speaker highlights into `notes.md`; budget calculation uses `CHARS_PER_TOKEN = 3.0` and splits over-long turns so prompts never silently clip ([notes.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/meeting/notes.py#L65-L234), [config.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/config.py#L1960-L1966)).

## Known pitfalls (top Linux/Wayland issues from the tracker)

- **No hardware-verified GNOME/KDE Wayland dictation yet**: [#643](https://github.com/MSKazemi/yazses/issues/643) blocks claiming "full Wayland" until real hardware tests pass on GNOME and KDE Wayland; open validation slots exist for Fedora/openSUSE/EndeavourOS KDE Wayland ([#171](https://github.com/MSKazemi/yazses/issues/171), [#181](https://github.com/MSKazemi/yazses/issues/181), [#211](https://github.com/MSKazemi/yazses/issues/211), [validation-matrix.md](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/docs/validation-matrix.md#L64-L68)).
- **Prompt echoes on silent bursts**: [#598](https://github.com/MSKazemi/yazses/issues/598) documents Whisper echoing the `initial_prompt` (`"The app is called YazSes."`) on noise/clicks that pass the RMS energy gate; led to adding the bundled Silero `speech_presence_check` ([speech_presence.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/audio/speech_presence.py#L3-L18)).
- **`ydotool` 0.1.x vs 1.x incompatibilities and stale sockets**: Ubuntu/Debian ship 0.1.8 (ignores `--socket-path`, binds `/tmp/.ydotool_socket`, exits 0 on parse errors, types first letter of unknown key names), and a user `ydotoold` without `/dev/uinput` write access binds its socket then crash-loops ([auto.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/inject/auto.py#L27-L42), [auto.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/inject/auto.py#L159-L171), [ydotool.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/inject/ydotool.py#L30-L43)).
- **Qt overlay steals focus on Wayland**: `WindowDoesNotAcceptFocus` has no Wayland equivalent, so showing a Qt overlay steals focus and swallows dictated text ([daemon.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/core/daemon.py#L290-L307)).
- **No toggle mode**: [#869](https://github.com/MSKazemi/yazses/issues/869) tracks adding press-to-start / press-to-stop toggle mode.
- **Wayland semantic targeting / libei**: [#102](https://github.com/MSKazemi/yazses/issues/102), [#418](https://github.com/MSKazemi/yazses/issues/418), and [#818](https://github.com/MSKazemi/yazses/issues/818) track Wayland `libei` injection and GNOME/KDE Wayland assistive-tech targeting limits.

## Ideas for the recorder

- **Copy: Silero speech-presence gate at 0.3 threshold before Whisper decode**: RMS energy alone lets fans and key clicks through, and Whisper echoes `initial_prompt` on noise ([#598](https://github.com/MSKazemi/yazses/issues/598)). A Silero gate at `0.3` (failing open) drops noise without clipping short single-word utterances ([speech_presence.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/audio/speech_presence.py#L35-L51)).
- **Copy: Critical-token + boundary-number guards on LLM cleanup**: Verifying output length ratio (`[0.5, 2.0]`) and preserving proper nouns, code identifiers, and boundary-matched numbers (`(?<![\w.])100(?!\w)`) prevents silent LLM hallucinations or altered figures, falling back to raw ASR text on rejection ([llm_cleanup.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/postprocess/llm_cleanup.py#L110-L215)).
- **Copy: Guarded post-decode glossary corrector (`vocab_correct.py`)**: Matching misheard domain terms via exact consonant phonetic key + bounded Levenshtein distance (ignoring words < 4 chars, stopwords in multi-word windows, and already-valid terms) works independently of Whisper's 223-token `initial_prompt` limit ([vocab_correct.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/postprocess/vocab_correct.py#L13-L73), [vocabulary.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/stt/vocabulary.py#L26-L46)).
- **Copy: Evdev multi-keyboard hotplug listener with virtual-device filtering**: Watching all real keyboards in `/dev/input`, excluding virtual uinput devices (`ydotool`, `uinput`, `virtual`), starting immediately on modifier key-down (`Right Alt`), and ending the hold if the device unplugs is clean and compositor-independent on KDE Wayland ([evdev_hold.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/hotkeys/evdev_hold.py#L18-L278)).
- **Copy: Sample-offset timestamps and batch decode-collapse quality check**: Stamping live utterances with audio-sample offsets (`last_start_s`) prevents drift under decoder load, and comparing batch word count against live transcript word count plus trigram repetition ratios catches Whisper loop collapses before deleting or summarizing audio ([segmenter.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/meeting/segmenter.py#L11-L18), [quality.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/meeting/quality.py#L1-L60)).
- **Copy: `wl-copy` settle delay + `ydotool` dialect/socket checks**: Waiting ~150 ms after `wl-copy` before sending paste prevents intermittent empty pastes on Wayland, and probing `ydotool` 0.1.x vs 1.x plus `/dev/uinput` writability avoids silent failures ([clipboard.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/inject/clipboard.py#L12-L41), [auto.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/inject/auto.py#L27-L185)).
- **Avoid: Spawning a regular Qt top-level overlay on Wayland**: Without layer-shell, a Qt overlay steals focus on Wayland and eats dictated text ([daemon.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/core/daemon.py#L290-L307)).
- **Avoid: `silero-vad` Python package on Linux CPU installs**: It pulls `torch` and CUDA (~3 GB); load the Silero ONNX model directly with `onnxruntime` instead ([silero_vad.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/meeting/silero_vad.py#L11-L20)).
- **Avoid: `condition_on_previous_text = True` on `large-v3` and skipping clipboard restore**: YazSes measured nondeterministic repetition loops on `large-v3` when conditioning is on ([config.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/config.py#L81-L101)), and its clipboard paste path clobbers the user's clipboard and sends `Ctrl+V` even into terminals ([clipboard.py](https://github.com/MSKazemi/yazses/blob/8ecfd4aeadcdeea8590754445653854ddc2ae82a/src/yazses/inject/clipboard.py#L35-L56)).
